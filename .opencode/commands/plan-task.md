Analiza la solicitud del usuario como una tarea de Scouting.pe.

1. Lee las instrucciones globales y documentos relevantes.
2. Clasifica la tarea como frontend, backend, full-stack, database/infra, docs o QA.
3. Identifica dependencias, archivos probables y riesgos.
4. Propón criterios de aceptación verificables.
5. Si la tarea es mediana o grande, añade una tarjeta a `docs/tasks/queue.md` con estado `PLANNED`.
6. No modifiques código de implementación durante esta fase.
